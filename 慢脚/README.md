## 小目标3——常见错误
1. 同一项目下多个main方法
	无法判断程序入口，会出现报错
	如何定位：输出：找到一个或多个多重定义的符号，给改个方法名看看能不能运行
2. 指针越界
	输出会出现很奇怪的数值，但不想py，java报错。修改不在范围内的也可能出现问题
	如何定位：查看是否有异常值出现
3. **中文编码问题
	输出中文乱码，同时程序出现异常报错，如“字符串字面量中的换行符”，“语法错误: 缺少“;”(在标识符“cout”的前面)”。原因是解码错误中文被错误解码出其他东西**
## 小目标4——一个字符串相关方法
### 方法名：length
- 作用：返回字符串长度
- 参数：无
- 返回值：int
- 示例：
